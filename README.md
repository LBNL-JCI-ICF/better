# Building Efficiency Targeting Tool for Energy Retrofits (BETTER)

> **This repository has been superseded.**
>
> The open-source building energy analytics library is now maintained at:
>
> **[BETTER-LBNL-OS](https://github.com/LBNL-ETA/better-lbnl-os)** - Modern Python library with improved APIs, documentation, and active maintenance.

This repository contains the original BETTER analytical engine developed under Cooperative Research and Development Agreement (CRADA) No. FP00007338 between Lawrence Berkeley National Laboratory and Johnson Controls, with assistance from ICF.

For historical reference, see the [legacy documentation](LEGACY_README.md).
